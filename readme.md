
## DestByte8


DestByte8 is a 8-bit CPU architecture built entirely from scratch, designed for general-purpose computing.

## Project Objective
To design, implement, and evolve a  instruction set architecture (ISA) and processor core from the ground up.



## Requirements if you want to test on a verilator

* Have verilator installed.
* Have any linux system.
* Having these requirements use this command: `chmod +x run.sh` `./run.sh`.
